21 октября 2026 года. Windows 11 x64, Python 3.12.14, Telethon 1.45.0 (TL layer 229), PySide6 Essentials 6.12.0, PyInstaller 6.22.3.

## Выполнено

**60 автоматических тестов — успешно.** Тесты выполнялись на временных данных, без соединения с Telegram:

- 90 слотов с интервалом 16 минут, переход суток, существующие сообщения, заполнение свободных промежутков, ограничения длины и близких дат.
- Миграция прежней базы, сохранение random_id и аккаунта, читаемая резервная копия, отсутствие повторного резервирования уже мигрированной базы.
- Независимые профили, сохранение старой сессии, удаление из списка/восстановление, запрет дублирования идентичности аккаунта.
- Реальный Windows DPAPI на синтетических секретах и сохранение/восстановление синтетической Telethon StringSession без открытого текста.
- Mock-авторизация с кодом и 2FA; GUI-переключение профилей и сохранение назначений шаблонов; часовой пояс не меняет момент времени.
- Создание с различными шаблонами по чатам, подтверждение повторения из ответа mock-сервера, отсутствие повторной отправки, сохранение прогресса, потерянные ответы, заполненная очередь.
- Упорядочение ближайших слотов между чатами; изменения очереди перед применением; предотвращение слишком раннего сообщения после последней публикации.
- FLOOD_WAIT/SLOWMODE_WAIT, сохранение ожидания, отмена и корректное продолжение.
- Смена ID после повторения, допустимый сдвиг времени, отказ при неоднозначности или большом сдвиге, ручная привязка.
- Массовое редактирование, сохранение повторения, возобновление после потерянного ответа без второго изменения, продолжение других чатов при локальной ошибке.
- Включение/выключение повторения, удаление, ограничение тестового режима.

DPAPI-проверки запускались в обычном пользовательском контексте Windows: ограниченная среда не имеет доступа к его криптографическим ключам. Использовались только искусственные секреты тестов.

Исходный интерфейс отрисован с синтетическими данными без Telegram. Скриншоты находятся в screenshots/.

**Пересобранный EXE успешно запущен автономно:** код завершения 0, время 3,97 секунды; журнал сообщает Telethon 1.45.0; repeat API: True. Создания Telegram-сессии не было. Машинный результат сохранён в validation-results.json.

Установленная библиотека и библиотека внутри EXE имеют параметр schedule_repeat_period. Это проверка доступности схемы, а не подтверждение прав конкретного аккаунта.

## Не проверено на реальном Telegram

Реальная авторизация, Premium конкретного аккаунта, создание/редактирование/удаление на сервере, ежедневная публикация и повторное планирование через 24 часа. Mock-тесты не доказывают эти свойства реального сервера. При использовании приложение проверяет фактический результат через Telegram API и останавливает неподтверждённую операцию.

Windows 10 и другой компьютер отдельно не проверены. Цифровой подписи и установщика нет. Порядок пользовательского теста одним сообщением приведён в GUIDE_V3.md. Никаких реальных публикаций при разработке не выполнялось.


## Дополнительные проверки v3

- Одна пара API ID/API Hash используется двумя mock-аккаунтами, с независимыми объектами сессий и разными идентификаторами аккаунтов.

- Восстановление сессии не запрашивает новый код; истёкшая сессия сообщает о необходимости входа.
- Миграция базы именно v2→v3 сохраняет незавершённые операции/random_id; backup содержит исходную схему v2.
- Циклы 16/31/61 минута содержат соответственно 90/46/23 слота, целочисленные интервалы, безопасную границу суток.
- Запас по умолчанию 60 секунд, ручное увеличение, запрет уменьшения ниже 60.
- HTML/UTF-16 сущности, форматирование при создании, изменение только оформления после смены ID с сохранением периода.
- История версий сохраняет изменения формата и не дублирует одинаковые версии.
- Диагностика фиксирует сдвиг, конфликт интервала, отсутствующее и дополнительное сообщение, не придумывая подтверждение доставки.
- Полученные события отправки дедуплицируются и учитываются только после проверки идентичности аккаунта.
- Полное удаление только ранее отключённого профиля не затрагивает общие реквизиты и другой профиль.
- GUI: общая пара API и HTML-шаблон сохраняются при переключении профилей.
